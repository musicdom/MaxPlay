# Подарки

Платформа для отложенных подарков: отправитель создаёт сюрприз, задаёт дату и время открытия, получает ссылку и делится ею в MAX.

## Стек
- Next.js App Router
- Neon Postgres для постоянного хранения
- Vercel Blob для изображений
- MAX Bot API для уведомлений и привязки получателей
- Vercel Cron для проверки сроков

## Правила
- До даты открытия подарок закрыт.
- С даты открытия есть 12 часов на получение.
- Открытый вовремя подарок сохраняется в профиле.
- Неоткрытый за 12 часов подарок получает статус expired и больше не показывается.

## Настройка
Скопируйте файл .env.example в .env.local и заполните секреты. Не добавляйте токены в Git.

Начальный интерфейс создан. Серверное хранение, MAX-авторизация, отправка сообщений, загрузка файлов и cron-обработка подключаются следующим этапом. GitHub Pages не может обеспечить эти серверные функции самостоятельно.
